# 01 · 安装

装这个插件是**加一个目录**。没有 pip、没有数据库迁移命令、没有要改的启动脚本。

## 0. 先确认你手上是什么

你需要一个能跑起来的 scbot-new 内核，目录里至少有：

```
scbot-new/
├── serve.py          ← 启动入口
├── app.py            ← 装配 App 和插件
├── core/             ← 内核
├── plugins/          ← 其它插件
└── characters/       ← 人设
```

先把它跑起来，网页端能对话，再装 QQ。**这一步别跳**：一个连网页都起不来的内核，
装完 QQ 只会多一个变量。

```bash
cd scbot-new
python -c "import sys; print(sys.version)"   # 需要 3.11 或更高
python serve.py --fake                        # 假模型，不需要 key
# 打开 http://127.0.0.1:8100 看到页面 → 内核没问题
```

## 1. 拷目录

```bash
cp -r qq-channel/channels /path/to/scbot-new/
ls /path/to/scbot-new/channels
# __init__.py  config.py  qq.py  plugin_qq.py  presence.py  ...
```

拷进去就行 —— `channels/` 里所有内部引用都是相对的，放在内核根目录即可，不需要装成 Python 包。

## 2. 确认内核有生命周期钩子

QQ 通道是唯一一个"自己开线程、自己连 socket"的插件，它需要内核在启动时调 `start()`：

```bash
cd scbot-new
python -c "from core.plugin import Plugin; from core.host import Host; \
print('start/stop:', hasattr(Plugin, 'start') and hasattr(Plugin, 'stop')); \
print('host.start:', hasattr(Host, 'start'))"
```

两行都是 `True` 就直接下一步。有一行 `False` → [06-内核补丁](06-内核补丁.md)，照抄二十行代码。

## 3. 装 NapCat

QQ 那边要有一个登录着小号的 OneBot 实现。这个包不带你，因为它是"账号"不是"代码"。
最快的方式是 Docker，见 [03-NapCat](03-NapCat.md)。

装完你要拿到两个值：**WebSocket 地址**（例如 `ws://127.0.0.1:3001`）和**token**（没设就空）。

## 4. 配置

把 `templates/env.qq.example` 的内容追加到内核的 `.env`，然后改这三项：

```ini
QQ_ENABLED=1
QQ_SELF_ID=机器人QQ号
QQ_CHARACTER=角色ID
```

再加一个去向，二选一或都写：

```ini
QQ_GROUP_IDS=群号            # 待在这个群
QQ_PRIVATE=1                 # 允许私聊（谁能私聊见 QQ_PRIVATE_IDS / QQ_OWNER_IDS）
```

逐项说明在 [02-配置](02-配置.md)。**先只填这五行，跑通了再加别的**——一次改十个变量，
出了问题不知道是哪个。

## 5. 角色文件

最少要两个文件（模板见 [04](04-自定义角色.md)）：

```
characters/<角色ID>.md              人设。没有它，她只能用世界知识胡诌
characters/world/<角色ID>-qq.md     群聊规则。没有它，她会用写小说的方式在群里说话
```

`<角色ID>` 必须和 `.env` 里的 `QQ_CHARACTER` 一模一样。**代码不猜**：名字对不上，
日志会写 `QQ 通道没有启动：QQ_CHARACTER 是空的`，或者用一份中性规则说话。

## 6. 启动

```bash
python serve.py
```

正常的话，启动行下面会多一行：

```
QQ 通道已启动：群 123456 / 角色 <角色ID> / ws://127.0.0.1:3001
```

没有这一行，或者写的是 `QQ 通道没有启动：…`，照着后半句改 —— 那句话就是诊断。
然后再问一次服务自己：

```bash
curl -s localhost:8100/api/qq/status | python -m json.tool
```

里面 `"running": true`、`"connected": true` 才算真的接上了（`problem` 为空、`last_error` 为空）。
到这里在群里 @ 她一下，应该就有回音了。

## 7. 装完自检（可选）

```bash
python tools/check.py            # 在包目录里跑；它会读内核的 .env 并报告缺什么
```

## 卸载

```bash
rm -rf /path/to/scbot-new/channels     # 就这么简单
```

内核会回到"只有网页版"的状态。数据库里的 `qq_*` 表留着不动 —— 它们是数据，不是代码，
删了聊天记录就没了。要一并清掉，见 [05-排错](05-排错.md) 最后一节。

## 这些文件是干什么的

| 文件 | 干什么 | 你要改吗 |
|---|---|---|
| `channels/config.py` | 所有 `QQ_*` 环境变量的读取与校验 | 不改 |
| `channels/onebot.py` | OneBot v11 的 WebSocket 客户端 | 不改 |
| `channels/ws.py` | 最小 WebSocket 协议实现（标准库，无依赖） | 不改 |
| `channels/qq.py` | 频道主体：收消息、合并、决定回不回、发出去 | 只在改指令文案时动 |
| `channels/plugin_qq.py` | 插件外壳：生命周期、`/api/qq/*`、定时任务 | 不改 |
| `channels/presence.py` | 每轮的那几段规则（对面是谁、能接多少） | 不改（改 `-stage.toml`） |
| `channels/world.py` | 同事/角色名册与设定文件的按名检索 | 不改 |
| `channels/identities.py` | QQ 号 ↔ 内核 user id、说过几次话、恋爱标志 | 不改 |
| `channels/stickers.py` | 表情包：收录、命名、挑选、发送 | 不改 |
| `channels/outbox.py` | 发送队列（失败重试、分段） | 不改 |
| `channels/digest.py` | 把聊天重写成记忆文件 | 不改 |
| `channels/texts.py` | 拒绝时说什么（台词在 `-refusals.toml`） | 不改 |
| `channels/stage.py` | 读 `-stage.toml` 的小工具 | 不改 |
