# 06 · 内核补丁（只有旧内核需要）

**先检查要不要看这一页：**

```bash
cd /path/to/scbot-new
python -c "from core.plugin import Plugin; print(hasattr(Plugin, 'start'))"
```

打出 `True` → 不用看了，你的内核已经支持。打出 `False` → 需要加四处，一共二十来行。

为什么需要：QQ 通道是唯一一个"自己开线程、自己连 socket"的插件。内核原本的插件只有
回合钩子（`before_turn` / `prompt_sections` / `after_turn`），没有"启动"和"停止"这两个时刻，
所以通道只能被 `serve.py` 硬编码挂载 —— 那样就不叫即插即用了。

---

## 1. `core/plugin.py`：两个默认方法

加在 `Plugin` 类里，`after_turn` 之后：

```python
    # ---- the lifecycle, for the few plugins that have one

    def start(self) -> None:
        """Called once, after every plugin is constructed and its tables exist.

        Most plugins never override this: a turn hook needs no beginning. It is here for the
        ones that are not only a turn hook — a socket to open, a thread to run, a timer to
        arm — because "a feature you can drop in" and "a feature that starts itself" are the
        same requirement, and the host is the only place that knows the order.

        Raising is allowed and not fatal: the host writes the plugin off with the reason and
        carries on serving turns without it. A channel that cannot connect must not take the
        page down with it.
        """
        return None

    def stop(self) -> None:
        """Called once on shutdown, in reverse order of `start`."""
        return None
```

## 2. `core/host.py`：按依赖顺序启动

`__init__` 里加一个字段（放在 `self._off` 后面）：

```python
        self._started = False
```

然后加两个方法（放在 `migrate` 之后）：

```python
    def start(self) -> list[str]:
        """Bring every enabled plugin up, in the same order the hooks run.

        A plugin that raises here is switched off like any other that cannot run, and so are
        the ones that required it. The kernel keeps serving turns. Returns the names that
        made it, which is what `serve.py` prints.
        """
        if self._started:
            return self.names
        self._started = True
        failed: set[str] = set()
        for plugin in list(self._order):
            missing = [need for need in plugin.requires if need in failed]
            if missing:
                failed.add(plugin.name)
                self._off[plugin.name] = "needs " + ", ".join(missing)
                continue
            try:
                plugin.start()
            except Exception as exc:
                failed.add(plugin.name)
                self._off[plugin.name] = f"start failed: {type(exc).__name__}: {exc}"
        if failed:
            self._order = [plugin for plugin in self._order if plugin.name not in failed]
        return self.names

    def close(self) -> None:
        """Stop what `start` started, newest first. Never raises: we are already leaving."""
        for plugin in reversed(self._order):
            try:
                plugin.stop()
            except Exception:
                pass
        self._started = False
```

## 3. `app.py`：可选装载

在 `Host(...)` 之前，把通道放进插件列表（`if self.gifts is not None: ...` 之后）：

```python
        # QQ 通道是唯一一个自己开线程、自己连 socket 的插件。它属于「可以整个拿走」的那一层：
        # 目录不在，`_qq_plugin` 返回 None，下面照常起一个网页版。
        self.qq = _qq_plugin(self)
        if self.qq is not None:
            plugins.append(self.qq)
        self.host = Host(plugins, judge=self.judge)
```

文件末尾（任何模块级函数旁边）加：

```python
def _qq_plugin(app: "App") -> Any | None:
    """The QQ channel, when this checkout has one.

    A deployment that never heard of QQ has no `channels/` directory, and that is not an
    error: the import fails, this returns `None`, and the page still talks.
    """
    try:
        from channels.plugin_qq import QQService
    except ImportError:
        return None
    return QQService(app)
```

如果 `app.py` 顶部没有 `from typing import Any`，补上。

## 4. `serve.py`：启动与停止

`main()` 里，`App(...)` 之后加一行，`finally` 里加一行：

```python
    app = App(settings, ScriptedLLM(FAKE_REPLY) if fake else None)
    app.host.start()                                   # ← 新增
    server = ThreadingHTTPServer(
        (settings.host, settings.port),
        make_handler(app, PAGE.read_bytes()),
    )
    ...
    finally:
        server.server_close()
        app.host.close()                               # ← 新增
        app.close()
```

如果老版本里有 `_mount_qq(app)` 和 `channel.routes()`，那两处一起删掉：
通道已经是 `host` 里的插件，`app.host.routes()` 里已经有它自己的 `/api/qq/*`。

## 验证

```bash
python -c "from core.plugin import Plugin; from core.host import Host; \
print(hasattr(Plugin, 'start'), hasattr(Host, 'start'))"
# True True

python serve.py --fake
# 有 QQ_* 配置时：QQ 通道已启动：群 ... / 角色 ...
# 没有配置时：什么也不打印（这是对的，没人要求它跑）
```

没有 `channels/` 目录时，内核必须照常起 —— 这是这个补丁唯一要保住的性质：

```bash
mv channels /tmp/channels-hidden
python serve.py --fake        # 页面照常
mv /tmp/channels-hidden channels
```
