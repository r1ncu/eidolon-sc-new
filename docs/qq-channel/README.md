# QQ 通道 · scbot-new 插件

把一个 scbot-new 内核（Eidolon-SC 的内核重构版）接到 QQ 上：群聊里被 @ 会答、
没被 @ 偶尔自己说话、私聊聊得来、表情能收能发、聊天会变成一份会被重写的记忆文件。

**它是一个目录，不是一台服务。** 把 `channels/` 拷进内核根目录，填几行 `.env`，重启，它就接上了；
把目录删掉，内核照常跑网页版。没有安装脚本、没有数据库迁移命令、没有要改的 `serve.py`。

```
qq-channel/
├── channels/         ← 全部源码。拷到内核根目录就是安装
├── templates/        ← 角色文件与 .env 的模板，照着写
│   ├── env.qq.example
│   └── world/example-qq.md · example-dm.md · example-stage.toml · example-refusals.toml
├── docs/
│   ├── 01-安装.md
│   ├── 02-配置.md
│   ├── 03-NapCat.md
│   ├── 04-自定义角色.md
│   ├── 05-排错.md
│   └── 06-内核补丁.md
└── tools/check.py    ← 装完跑一下：能不能导入、配置缺什么
```

## 它不带你什么

| 不带 | 为什么 | 你要自己准备 |
|---|---|---|
| NapCat / OneBot 实现 | 它需要扫码登录，是账号的事，不是代码的事 | 一个登录着小号的 NapCat，开 WebSocket 服务器（[03](docs/03-NapCat.md)） |
| 模型 API key | 密钥不该出现在分发包里 | 任何 OpenAI 兼容服务的 key |
| 任何角色数据 | 人设、台词、记忆都该是你写的 | 一个 `<角色ID>.md` + 两份 world 文件（[04](docs/04-自定义角色.md)） |
| 数据库、表情、日志 | 都在你的数据卷里 | 什么都不用做 |

## 能力

- **群聊**：被 @ 必答（不经过判断）；**叫了她的名字**但没 @ 时，她读上下文自己决定接不接——
  可以回三行前那个问题，可以说一句自己的事，也可以一句都不说。一天最多 `QQ_AMBIENT_DAILY`
  次（所有群加在一起），依据是角色自己的插话清单。
- **提到她就算叫她**：`@ 她`和消息里**叫她的名字**（`names.mentions`）是一回事——她都会结合
  最近几行上下文自己判断要不要回，不回也是回答的一种（日志里写为什么）。这一处是 fail-open：
  判断模型挂了她照回，被叫到却沉默看起来像坏了。`QQ_CALLED=0` 回到旧行为。
- **私聊**：白名单制，默认关。名单里的人一对一聊，用的是另一套语气文件。
- **两条场次不串**：群聊和私聊的好感度分开记，群里的表现不会污染私聊里的关系。
- **熟稔度阶梯**：同一个人说得越多，语气越近。阶梯写在角色文件里，阈值你定。
- **恋爱状态**：好感和说话次数两道门都过了才进；进入之后好感度难掉，她会不定时先发消息。
- **表情**：收录群里发的表情、也能用这个号收藏的表情；`/表情` 讨一张。
- **读得懂表情标记**：群友发的小黄脸和收藏表情，进提示词时写成 `[表情]` / `[表情 名字]` / `[动画表情]`。
  她看得见的是"他按了一个表情"，不是那张图；整条只有表情也算一句话，会照常回。
  连续刷同一个表情会折叠成三个（四十连和三个说的是同一件事）。
- **记忆文件**：每 N 天把聊天重写成一份 `characters/memory/*.md`，新的盖掉旧的；这份文件会回到提示词里。
- **记忆不串场**：私聊里记下的只会在私聊里被想起，群里记下的只会在群里被想起。在群里和制作人
  说话时，她也不会提私聊里的事——两边是两份记忆，不是一份记忆的两个读者。
  网页（设置页）里能看到全部，每条带「私聊 / 群聊 / 网页」标签。
- **图片**：群里发图她会看（需要视觉模型），也能回图。
- **运维接口**：`GET /api/qq/status` 说清楚它在不在线、为什么不说话；`/重载` 改完人设立刻生效。

## 5 分钟

```bash
# 1. 拷目录（内核根目录 = 有 serve.py 和 app.py 的那一层）
cp -r channels /path/to/scbot-new/

# 2. 配置：把 templates/env.qq.example 追加到内核的 .env，至少填这三项
#    QQ_SELF_ID=机器人QQ号
#    QQ_CHARACTER=角色ID
#    QQ_GROUP_IDS=群号

# 3. 角色：写 characters/<ID>.md（人设）和 characters/world/<ID>-qq.md（群聊规则）
#    模板在 templates/world/，复制改名即可

# 4. 起内核，看这一行
python serve.py
# QQ 通道已启动：群 123456 / 角色 <ID> / ws://127.0.0.1:3001
```

看到 "QQ 通道已启动" 之前，先看 [03-NapCat](docs/03-NapCat.md)：**十次里有九次连不上，是 NapCat
那边的 WebSocket 没开或者端口不对，不是这个插件的问题。**

## 版本要求

需要内核的插件系统带生命周期钩子（`Plugin.start/stop`、`Host.start/close`），也就是
**scbot-new ≥ 1.4.3**。旧内核看 [06-内核补丁](docs/06-内核补丁.md)，只有二十来行。
