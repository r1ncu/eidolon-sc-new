# 角色资料（`facts/`）

这里放每位角色的资料，文件名就是 `characters.toml` 里的 `id`：`facts/mano.md`、`facts/hiori.md`。
没有文件就等于没有资料，人设（`sheets/`）照常工作。

格式和 `sheets/` 一样是 Markdown，区别只在于**标题就是检索的单位**：

```markdown
# 櫻木真乃

## 喜欢的东西
喜欢鸟，家里养着一只叫ピーちゃん的鸽子；休息日会去公园看鸽子。

## 最近的事
下个月有一次考试，有点不安，正在和制作人一起复习。
```

上面这份会切出两段：「喜欢的东西」和「最近的事」。向量版每次只带最相关的几段，所以
**一段讲一件事**比写成一大段更好用；一段太长时会在空行处再切开。

## 三种用法（`SCCORE_RECALL`）

| 值 | 资料怎么进提示词 | 需要什么 |
|---|---|---|
| `off`（默认） | 不参与 | — |
| `whole` | 整份贴进人设，跟人设一起缓存 | — |
| `vector` | 切段嵌入，每轮带最相关的 `SCCORE_RECALL_TOP` 段 | 一个 OpenAI 兼容的 `/embeddings` |

改完 `.env` 重启即可切换，不用改代码、不用重导数据。细节、代价与失败行为见
[`docs/deploy.md`](../docs/deploy.md) 的「角色的资料：数据版还是向量版」。

> 本目录刻意是空的：上游的角色资料由剧情与官方设定整理而来，不含可再分发的许可证。
> 用自己的资料，或者留空。
